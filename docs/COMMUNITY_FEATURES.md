# 🎵 GTM community ideas and feature requests

GTM is a **music-first Steam Deck plugin** maintained by Valentine. In the current **4.4.9** release, Arcade-themed visualizers are **automatic AI spectator scenes**, not human-playable games. The playable Arcade and early-alpha Chess described in older 4.4.1 notes are historical experiments, not active 4.4.9 features.

A GitHub account is needed to comment, file an issue, or react.

## What feedback helps?

Describe what you're trying to do on your Steam Deck, what happened and what you'd rather see. Suggestions involving visualizers, color palettes, accessibility, controller navigation, soundtrack automation, playlists, Ambient/Store playback, music discovery, ResonaDeck cooperation and performance are all welcome.

For spectator scenes, mention which visualizer, the observed AI behavior, power effects, ball physics mode, selected layout and whether a different CSS Loader theme is in use. Provide a screenshot or clip if convenient, **not because it is required**. Avoid including account tokens, private files or logs with personal details.

## How requests are evaluated

Look for existing ideas first; supporting a related issue is helpful. If yours is different, open a new request. Proposed changes are judged by usefulness, technical feasibility, Steam Deck performance, compatibility and maintenance cost. An issue may be marked Suggested, Under Review, Accepted, In Development, Preview Testing, Released or Not Planned. **Votes are signals, not promises or deadlines.**

The community poll currently uses reactions on the *individual option comments*. GitHub Discussions is not enabled for this repo, so Issues is the supported discussion channel.
