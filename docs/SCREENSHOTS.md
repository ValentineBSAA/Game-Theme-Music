# GTM image gallery: historical captures and current hardware status

## Current version: 4.4.9

The maintainer has physically verified that **4.4.9 shows Valentine's full-screen Steam Home welcome** and that **Neon Paddle AI versus AI scores a genuine goal**. The real 4.4.9 TV photograph was supplied during testing but has **not been uploaded to this repository's gallery**. We do not substitute an illustration and label it as an actual 4.4.9 screenshot.

To see GTM's latest features, start with the [4.4.9 release notes](RELEASE_NOTES_4.4.9.md) and [Getting Started](GETTING_STARTED.md). The images below are historical, not proof of the current menu layout.
