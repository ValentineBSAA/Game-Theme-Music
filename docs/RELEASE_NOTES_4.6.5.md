# Game Theme Music 4.6.5 | Stable maintenance, controller polish and shared visualizers

**Developer:** Valentine  
**Status (November 6, 2026):** Stable build accepted during maintainer Steam Deck testing. **The release asset has not yet been uploaded to GitHub.** The currently available public download remains V4.5.8. Do not download GitHub's autogenerated source ZIP as the Decky installer.

## What's changed since the published 4.5.8 build

### Customizable Steam Library context menu (resolves #10)

Three independent GTM shortcuts now have independent visibility settings: **Change Music**, **Change Ambient Playlist** and **Change Store Playlist**. You can leave any combination visible. Hiding a shortcut does **not** turn off its music feature, clear a playlist or modify TitleDeck's own entries. The maintainer verified mixed toggle combinations on Steam Deck, including hiding only Ambient while retaining Music and Store.

### Faster, steadier Quick Menu navigation

- **Browse all pages · A–Z** provides a dropdown for direct section navigation, alongside LB/RB paging.
- Reduced conflicting automatic scrolling and focus operations during page changes.
- Reduced unnecessary background checks and repeated identical playlist-state storage writes while keeping important playback transitions persisted.
- More targeted theme observation and cleanup of long-lived listeners/bridges during hot reloads.

These changes reduce avoidable work; **no quantified Quick Menu speedup is claimed across SteamOS/Decky versions**.

### Store Music and Ambient reliability

A 4.6.3 Store Music regression was corrected in 4.6.4 by restoring the trusted playlist reconciliation path while avoiding identical storage writes. The maintainer reported Store Music working again on Steam Deck. Ambient, Store playlists, crossfade, and library audio controls remain supported.

### ResonaDeck 1.5.6: visualizer ownership fixed

- ResonaDeck's stored setting is no longer replayed as a fresh user ON command every time the bridge starts.
- A deliberate ON/OFF press in either plugin continues to control the live visualizer without stopping audio.
- With visualizers enabled but **no eligible playback**, the Home visualizer remains hidden. Starting supported music makes it appear. OFF hides the visualizer without stopping the track.
- This idle-versus-playing behavior was reported as **working** on the maintainer's Steam Deck with GTM 4.6.5 and ResonaDeck 1.5.6.

### Preserved

Game soundtracks, Ambient/Home and Store Music, player state and playlist functionality, original visualizer collections, CSS Loader adaptive colors, ResonaDeck music-frequency sharing, watch-only AI-versus-AI Arcade Spectator and **bundled YT-DLP/QuickJS downloader executables**. This update does **not** introduce human-playable Arcade multiplayer or change TitleDeck settings.
