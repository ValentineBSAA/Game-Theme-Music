# Game Theme Music 3.5.6 — Local Queue + Seamless Update Handoff

Game Theme Music 3.5.6 turns Local Import into a true controller-first Soundtrack Manager workspace and hardens playback continuity during Decky plugin replacement.

- Browse Music, Downloads, or Home directly inside the manager.
- Preview local audio before importing it.
- Build a multi-track queue, then import to the Library or add the batch to the current soundtrack.
- Music is now the default local folder.
- Deep YouTube discovery can continue to 500 usable results and explicitly distinguishes true exhaustion from safety limits.
- Store, Ambient, and game-theme playback can adopt the already-playing browser transport after an update instead of reloading the same song.
- Decky Store is no longer mistaken for Steam Store, reducing duplicate/restarted Store playback during update navigation.
- Native Decky focus remains the only D-pad owner. Import uses explicit vertical column flow, Left/Right between file and queue columns, and edge guards so lateral input cannot masquerade as vertical movement.

The known-good 3.0.7 live theme and controller foundation remains locked.
