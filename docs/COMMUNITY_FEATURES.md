# 🎵 GTM Community Ideas, Requests & Voting

Game Theme Music is built with hands-on Steam Deck testing and community feedback. Whether your idea is a small quality-of-life change or an ambitious new direction, this is where you can share it and help us see what matters to GTM users.

## How feature requests work

1. **Search first.** If someone has already described your idea, add a 👍 reaction and any useful context. That helps show interest without splitting feedback across duplicates.
2. **Describe the experience you want.** What are you trying to do on Steam Deck? Where would the feature fit? How would you know it worked well?
3. **Add an example if you have one.** Screenshots, mockups, or examples from other software can help but are optional. Avoid including private data.
4. **Share thoughts and vote.** Constructive conversation and reactions help reveal which problems matter most.
5. **Follow the issue.** The maintainer may ask questions or update its status as development evolves.

## How voting works

- **For individual requests:** Open a feature request Issue and click **👍** on its main post to show your support. Comments are best used for details and use cases.
- **For community priority polls:** Open the current poll Issue and click **👍 on the comment** for your preferred option. Please choose your favorite for a clearer signal. GitHub Issues cannot strictly enforce one choice per person, so treat this as informal feedback.
- **For a new suggestion:** Use the feature request form so that people can consider and support it independently.

Votes are valuable input, not a binding decision or a scheduled release date. Different requests vary in scope, performance costs, compatibility risks and maintenance effort.

## From idea to release

The maintainer may use the following statuses in issue updates or project tracking:

| Status | What it means |
| --- | --- |
| 💡 Suggested | Shared by the community and open for feedback |
| 🔍 Under Review | Feasibility, value or implementation details are being evaluated |
| 👍 Accepted | Selected for possible implementation; timing is not promised |
| 🛠️ In Development | Work on the feature is underway |
| 🧪 Preview Testing | An experimental version is available for testing |
| ✅ Released | Included in a published GTM release |
| 📌 Not Planned | Not moving forward at this time, with context when possible |

These statuses describe **decisions or real progress**, not automatic transitions. An idea remains a suggestion until the maintainer explicitly updates it. Not every accepted idea is guaranteed a release.

> ### How decisions are made
> We love hearing where the community wants GTM to go. Ideas are weighed against real-world usefulness, performance on Steam Deck, technical feasibility, compatibility, accessibility, maintenance and current development priorities. Some may become features; others may remain on the wishlist or inspire something different. **No suggestion, vote count or discussion creates a release commitment.** Final product and scheduling decisions stay with the maintainer.

## What makes a strong request?

A good request explains **the problem**, not only a preferred implementation. For example, rather than just writing "add an option," describe the menu or playback situation and what you need it to do. Feel free to suggest an exact interface, animation, or behavior, but it's okay if you don't know how it could be built.

Possible areas include:
- Music-reactive visualizers and immersive effects
- Interface themes, accessibility and customization
- Games, Ambient/Home, and Steam/Decky Store playback
- Soundtrack Manager, navigation and controller controls
- Music discovery, imports and playlist organization
- Performance, stability and compatibility

Please be respectful, stay on topic, avoid duplicate requests, and don't include confidential information in screenshots or logs.

## For the maintainer: optional GitHub Discussions upgrade

**Current public voting uses GitHub Issues and 👍 reactions.** GitHub Discussions and native multiple-choice Discussion polls are not currently enabled for this repository.

If the maintainer wants to add them later:

1. Open **Repository Settings → General → Features** and enable **Discussions**.
2. In Discussions, set up an **Ideas / Feature Requests** category where the community can discuss and upvote ideas.
3. Add a **Polls** category using the native *Poll* format for multiple-choice votes.
4. Pin or highlight a welcome discussion linking here, the request form, and the current roadmap or poll.
5. Update the README and this guide with direct Discussions links **after the categories are live**.

Issue requests remain useful for formal tracking of accepted work, regardless of whether Discussions is enabled.

This community process does not modify GTM's released plugin, audio playback, or current hardware validation.
