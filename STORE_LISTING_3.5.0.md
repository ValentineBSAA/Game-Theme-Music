# Game Theme Music 3.5.0 Store Listing

## Tagline
Your Steam Deck, with a soundtrack.

## Short description
Game Theme Music is a controller-first Steam Deck soundtrack manager with per-game playlists, Steam artwork, Ambient and Store music, seamless online discovery, local imports, offline playback/artwork, library tools, and live theme integration.

## Full description
Turn Steam Deck Gaming Mode into a soundtrack system. Give Steam and non-Steam games ordered playlists, create separate Ambient music for normal Steam browsing, and give the Steam Store its own playlist. The Games manager now shows Steam artwork for the selected title, making soundtrack editing feel tied to the game instead of a generic list.

Find Music is built for the Deck: type with Steam's keyboard, press R2 / Enter to search immediately, and the keyboard dismisses automatically. Results start with a fast 20-item batch and continue loading in the background as you approach the bottom, up to a bounded 80 loaded results per query. Preview remains separate from Download + Add, and downloaded tracks stay local-first.
