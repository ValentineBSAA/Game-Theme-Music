# Game Theme Music 4.4.2 Music-First Preview

**Unreleased / draft PR only.** This is not a published stable release.

4.4.2 derives from the checksum-verified 4.4.1 Public Beta installer. It removes playable Arcade game modes, gamepad takeovers, scoreboards, championships, Chess, interactive Pong and Arcade-specific settings. The Steam/non-Steam soundtrack manager, Ambient/Store playlists, crossfade, sleep/wake behavior, ResonaDeck audio cooperation, existing display settings, and reactive visualizer renderer are retained.

The old visual themes remain useful: twelve original Visual Worlds scenes survive, alongside five music-reactive *Visual Experiments* derived from the Arcade artwork. These five retain their old saved scene IDs but no longer run gameplay.

Automated GitHub Actions validated crossfading, focus recovery, sleep mode, renderer pacing, both built-in pack manifests, and custom-pack import restrictions. **A real Steam Deck install and regression pass are still needed before release or merging.**
