# Game Theme Music 3.5.5

## Deep YouTube Discovery

3.5.5 repairs Find Music pagination so filtered YouTube rows no longer masquerade as the end of search. Game Theme Music now keeps a continuing yt-dlp search session alive while you browse, reads valid tracks in 20-result chunks, and keeps going when long mixes are skipped.

Broad searches can now surface up to 200 usable tracks per query instead of the previous 80-result ceiling. Preloading begins earlier near the end of the visible list, and remote thumbnails are lazy-loaded to keep fast couch scrolling lighter.

3.5.4 premium Import, 3.5.3 notification artwork/update playback continuity, and the locked 3.0.7 live-theme/audio foundation are preserved.
