# Game Theme Music 3.0.2 hardware correction

This build is based on direct Steam Deck screenshots and behavior from 3.0.1.

- Physical LB/RB: current Decky input values 30/31.
- Ambient picker: stable keyed list, no remount-on-toggle.
- Ambient page: audible preview when enabled and populated.
- Legacy metadata: one bounded yt-dlp metadata batch can repair old ID-only titles without changing audio files.
- Contrast: Ambient and Store controls own their surfaces so CSS Loader cannot independently paint alternating rows.
