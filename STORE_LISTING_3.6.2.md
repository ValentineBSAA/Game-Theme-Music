# Game Theme Music 3.6.2

**Unified Store Session + Artwork Polish**

Game Theme Music 3.6.2 makes Decky/plugin Store and native Steam Store act like one soundtrack session. The same track, timestamp, shuffle queue and listening history follow you between Store surfaces and through plugin updates. Find Music now uses a clean three-card row rhythm, Ambient and Steam Store receive dedicated artwork, Steam game art uses safer framing, and local import progress remains visible long enough to read.
