# Game Theme Music 4.5.8 | Visualizer Renaissance & ResonaDeck Bridge

**Developer:** Valentine  
**Release type:** Stable public release · Published November 5, 2026  
**Published asset:** `Game-Theme-Music-4.5.8.zip`

This release advances GTM's music-first design with visualizer creativity, controller usability, crossfade playback, and two-way ResonaDeck interoperability.

## What's new
- **Six new built-in scenes:** Millennium Analyzer, Cyber Highway 2003, Glass Oscilloscope, Prism Loom, Celestial Clockwork and Liquid Hologram.
- **Visualizer navigation:** a controller-friendly two-column browser, direct directional movement, category/page arrows, always-visible ON/OFF switch, active-scene identification and a separate Custom / Imported collection.
- **More expressive animations:** revised music-reactive color smoothing and an upgraded dimensional black-hole scene. Additional scenes are offered as an optional extension pack ZIP.
- **Music crossfade:** improved dual-player overlap timing and volume envelopes, with an optional countdown/progress badge that can remain visible when visualizers are off.
- **ResonaDeck integration:** GTM and ResonaDeck can both toggle the live visualizer ON/OFF. Latest explicit action takes precedence, preserving the supported v1 bridge without lockstep version requirements.
- **Polish:** improved CSS theme contrast, more compact developer-branded one-time welcome, GitHub links, reorganized Game Card Music settings, and sleep/wake recovery safeguards.
- **Packaging:** retains yt-dlp, QuickJS, and core audio functions while removing developer test material from the installer.

## Compatibility and transparency
- ResonaDeck is optional. Visualizer controls work in GTM standalone.
- Steam Deck testing confirmed bidirectional control and successful ResonaDeck integration. Some audio-source-specific crossfade and sleep/wake cases can vary by environment.
- GTM remains focused on music and AI Arcade Spectator. Historical playable arcade experiments are **not** advertised as shipping features.
- Optional extension packs, when available, are separate from the GTM installer.
