# Game Theme Music 2.9.3 — No Auto-DJ stability build

Library Auto-DJ has been removed from the active plugin. The removal includes its Decky UI, bulk assignment workflow, Steam-library scanner RPC, result/stop modal handling, and Auto-DJ-specific CSS.

The core singleton AudioEngine and normal Game Theme, Ambient, Store, preview, playlist, provider, non-Steam, SAO HUD, and Media Bridge behavior remain unchanged from 2.9.1.
