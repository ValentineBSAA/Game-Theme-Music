### Published ZIP versus checked-in source

**The release's named ZIP remains the supported installable build.** The checked-in backend, compiled frontend, and both version manifests have now been copied byte-for-byte from the verified 4.6.7 installer. Packaged visual assets and development sources were also synchronized where present; see [verified runtime scope](docs/VERIFIED_RUNTIME_4.6.7.md). This does not establish that the repository can reproducibly rebuild every bundled binary, or that original development source files absent from the installer were recovered. The named ZIP remains authoritative for Decky installation.

Bundled **YT-DLP** and **QuickJS** executables remain in the installable ZIP. Large binaries and other third-party components may not exist in the repository checkout. GitHub's automatically generated **Source code** ZIP is not a full Decky installation archive.

### Release-tag history and synchronized source

The original `V4.6.7` tag was created before the 4.6.7 runtime source synchronization. Its historical `package.json` and `plugin.json` still identify version 4.5.8, even though the named published release installer correctly identifies version 4.6.7 and has a verified SHA-256 digest. This is a tag/source snapshot discrepancy, **not** evidence of a broken release ZIP.

The tag and downloadable installer were intentionally left unchanged. The synchronized 4.6.7 runtime is now tracked on the default branch through [the reviewed source repair PR #16](https://github.com/ValentineBSAA/Game-Theme-Music/pull/16), with exact copied file checksums in [the runtime manifest](docs/VERIFIED_RUNTIME_4.6.7.md). GitHub's autogenerated source-code archives for the original tag remain historical, and must not be treated as Decky installers.

### Verification and history

The maintainer physically verified both Store music surfaces, exit detection, the context-menu controls, ResonaDeck audio priority and enabled/idle visualizer behavior. Frequency response to ResonaDeck music was seen after refreshing its share toggle; automatic startup handshake has not been comprehensively verified. Syntax, ZIP integrity and focused regression checks were also performed during package preparation.

Previous releases [V4.5.8](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.5.8) and [V4.4.9](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.4.9) remain available for historical reference. No older installer is needed to install 4.6.7.
