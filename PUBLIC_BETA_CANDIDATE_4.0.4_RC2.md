# GTM 4.0.4 Public Beta Candidate RC2

Focused refinement build after live Steam Deck testing.

## Preserved
- Automatic 8-second crossfade from 4.0.3/4.0.4 remains untouched.
- Unlimited Ambient, Store and game playlists remain enabled.
- Visualizer Pack Manager and ResonaDeck visualizer bridge remain present.

## Removed / replaced
- Removed Aincrad Duel • Sword Combat.
- Removed Prism Forge.
- Removed Spirit Blade.
- Added Neon Pong.
- Added Supernova Bloom.
- Added Tidal Bloom.

## Refined scenes
- Disc Prism is larger and spans more of the footer.
- Beat Pinball uses multiple chambers instead of one chaotic footer-wide path.
- Seismic Mountains has clearer layered peaks and ridgelines.
- Mechanical Iris now appears as a wider footer array.
- Sakura Tempest uses smoother initialization and calmer, more natural drift.

## Importer status
- Demo add-on updated to only use supported refined effects.
- Future car / city racing pack intentionally deferred for a later importer-focused pack.
