# Getting started with Game Theme Music

**Published beta:** [GTM 4.1.2](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.1.2). **Earlier releases:** [4.0.4 Public Beta](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.0.4) and [3.7.0 Stable](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V3.7.0).

## Install or update
Install the published **[Game-Theme-Music-4.1.2.zip](https://github.com/ValentineBSAA/Game-Theme-Music/releases/download/V4.1.2/Game-Theme-Music-4.1.2.zip)**, using Decky Loader's manual ZIP install. Never install GitHub's autogenerated "Source code" ZIP. Preserve your existing music and saved settings.

## Ambient Sleep Mode (4.1.2)
Open **Full Manager → Ambient** and enable **Sleep Mode • delayed Ambient start**. Use the adjacent **Wake / restart delay**, adjustable from **5 to 60 seconds** (12-second default). After sleeping or restarting the Steam Deck, Ambient begins automatically *after* the delay, with a gentle fade-in. The maintainer has physically verified both the sleep/wake and restart scenarios.

## Music
**Games:** Steam and non-Steam game soundtracks. **Ambient:** Home music. **Store:** both Steam and Decky Plugin Stores share one Store Music session. Larger playlists are supported beyond the former 15-song cap. GTM can optionally prebuffer crossfade transitions for up to eight seconds.

## Visualizers
Choose a scene in one of four collections: Retro Ambient, Classic Rhythm, GTM Signature or Anime Worlds. GTM includes 22 built-in scenes, a ZIP Visualizer Pack Manager, reactive palettes, footer sizing/blending controls and **Shuffle All Visualizers**. Newer rendering smooths animation and aligns frames to available refresh rates as performance permits.

For Plex-reactive visuals, pair with **ResonaDeck 1.4.1**. Its Quick Access visualizer switch sends the music data to GTM (ON) or immediately clears the Plex-driven visualizer (OFF), without pausing Plex. GTM yields music playback focus while Plex plays.
