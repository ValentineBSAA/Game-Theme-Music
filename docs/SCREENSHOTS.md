## 4.4.1 Arcade: illustrative Neon Paddle visual

![Illustrative neon paddle scene, NOT a real hardware screenshot](screenshots/arcade/neon-paddle-illustrative.svg)

**Illustrative render only.** This is a designed visual representing the Neon Paddle Championship concept; it was not captured from actual 4.4.1 gameplay and does not claim exact UI, physics, particles or colors.

The maintainer reports actual on-device success with Pong multiplayer, Orbital Duel, Orbit Defenders and the enlarged Chess board. Because no clean verified 4.4.1 capture was supplied for publication, we're **not labelling a synthetic image as a gameplay screenshot** and not asking the user for a new one.
