# Game Theme Music 4.4.9: Screenshot Gallery 📸

**Actual 1920 × 1080 GTM 4.4.9 Steam Home and Quick Menu screenshots supplied by Valentine.** These are the **15 screenshots shared with this release**, **not the full visualizer collection**. Some scenes, powers, color variations, and packs are not pictured. Effects can appear differently depending on selected music, mode, palette, CSS theme and footer layout.

> ### 🎵 Prefer just the music? Visualizers are optional.
>
> Open **Quick Access → Game Theme Music → Visualizers → Enable Home visualizers** and switch it **OFF** to hide the animated footer. **Music playback keeps working** for game soundtracks, Steam Home Ambient music and Store music. Switch the same setting **ON** when you want visualizers again.
>
> **Shuffle all visualizers on track change** is a **separate** ON/OFF setting. Turning shuffle OFF keeps your scene selection instead of changing it on track changes; it does **not** disable visualizers or their built-in AI motion, effects, paddle changes or powers. **Couch/TV footer** only changes the visualizer's display size.
