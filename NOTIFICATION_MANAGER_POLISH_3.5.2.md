# Game Theme Music 3.5.2 — Notification Artwork + Manager Polish

3.5.2 is a focused follow-up to the hardware-tested 3.5.1 baseline.

## Now Playing artwork

The notification ribbon now prefers a cached inline `data:` image generated by the backend. This removes the dependency on Steam's overlay successfully fetching a remote thumbnail or a localhost artwork URL while Decky/plugin lifecycles are changing. Artwork larger than the bounded inline limit can still fall back to the normal loopback artwork server. A visual fallback always remains underneath the image, so an image decode/fetch failure cannot leave the notification tile blank.

## Game identity cleanup

Steam non-Steam shortcuts may appear as a 32-bit shortcut AppID or as Steam's 64-bit shortcut game ID. The backend now exposes both forms as aliases. Soundtrack Manager uses those aliases for names and collapses only entries proven to be the same Steam shortcut. This targets duplicate/Unknown entries such as ES-DE without deleting any saved soundtrack configuration.

## Faster assigned-track preview

When a game opens, GTM opportunistically resolves localhost URLs for its assigned/downloaded tracks in one bounded backend call. Pressing A to Preview can reuse the warm URL immediately instead of waiting for the first local-file RPC. Provider resolution remains a fallback only for legacy/non-local assignments.

## Hero polish

Game artwork remains the wider 3.5.1 hero format, with centered crop positioning for more consistent framing. If Steam has not populated the local library cache yet for a native game, the backend can cache first-party Steam CDN hero/header assets and then serve them locally to Decky.

## Baseline

3.5.1 is the new known-good baseline. Its exact-position update handoff, 3.5.0 R2/Enter search and paging, and the locked 3.0.7 live-theme/audio foundation are preserved.
