# Game Theme Music 2.7.26 mini player redesign

The mini player is now an SAO-inspired white/yellow HUD built directly in the plugin frontend. It uses the `SAO UI` font family when the active SAO Gaming Mode theme exposes it globally and falls back to narrow system fonts otherwise.

The card includes angular white clock-style geometry, yellow active accents, artwork when available, elapsed/total playback time, live progress, context labels, and queue metadata for Ambient/Store.

No audio-routing, non-Steam, playlist, or notification-trigger behavior was changed.
