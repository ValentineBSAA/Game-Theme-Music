# Playlist Workshop 3.0.5

Playlist Workshop replaces the old checkbox-like Ambient/Store picker.

- Current Playlist is always shown separately and remains ordered.
- A on a selected card removes it; A on an available card adds it.
- Dedicated up/down controls reorder without rebuilding the whole list.
- Downloaded/imported music has its own filterable section.
- Online search and local import remain available in the same editor.
- Add Visible, Clear Working List, and Reset Changes provide bulk operations.
- Every card exposes semantic status chips such as IN PLAYLIST, AVAILABLE, ONLINE, provider, size, and NEEDS NAME.
- The status thought explains what A will do and where the track currently lives.
- The editor keeps the 15-track global playlist limit and commits on Save/B-close.
