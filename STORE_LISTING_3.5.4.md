# Game Theme Music 3.5.4

## Premium Local Import

3.5.4 brings Import Local Music up to the same visual and controller standard as the rest of Soundtrack Manager. Game-target imports now show the selected game artwork, Ambient and Store receive themed destination art, and the page exposes clear destination, folder, and action context without crowding the TV layout.

The focus hierarchy is also rebuilt around Decky's native navigation: Up/Down traverses the import stack, Left/Right is reserved for the final two import choices, and LB/RB stays in the existing manager section rail.

3.5.3 notification artwork and seamless update-time local playback are intentionally preserved for hardware testing.
