# Game Theme Music 3.0.4

Hardware-feedback correction focused on the last presentation/navigation mismatches.

## Changes

- Read computed colors from each rendered element's owner window, not the plugin execution window.
- Learn the actual rendered controller-focus accent and apply it to interactive GTM controls.
- Use the theme accent for ON switch state, GTM focus rings, and sliders.
- Replace Health Center's legacy fixed navy gradients with semantic adaptive colors.
- Keep track-name repair results visible and lengthen the repair toast.
- Show up to 100 Music Library downloads at once with unambiguous count text.
- Group the brand banner and page rail into a single vertical controller focus path.
- Remove Health-row smooth-scroll calls that could fight Decky focus navigation.

Playback behavior, LB/RB page input, Ambient preview, Store, Media Bridge, and the 2.9.12 audio core are unchanged.
