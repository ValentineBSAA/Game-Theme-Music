## Rollback and configuration

Keep a backup of a known-working plugin package and your settings before updating. GTM saves playlists and options separately from the program files where possible, but storage behavior can vary with uninstall methods and Decky/SteamOS versions. Downgrading between versions with substantially different settings is not guaranteed to preserve everything. The **4.4.9 installer is standalone**, not an update patch.

The historical V4.4.1 tag is intentionally **not reissued as a release**. Its tag and older development notes are preserved only as historical context. Please do not restore or recreate the archive.
