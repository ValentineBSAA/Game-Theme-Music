# GTM 4.0.4 Public Beta validation

**Public prerelease after RC4 developer-owned physical Steam Deck testing.** Confirmed reported behavior: crossfade, 20+ Ambient tracks, imported Visual Worlds scenes, Pong fixes, custom pack install/remove, scene shuffle, Sakura/Tidal Bloom and Pinball improvements. Multiple JS and Python offline regression suites were run on RC4 for playback, routing, importer, collision and scene behavior.

**Not confirmed:** specific SteamOS/Decky version matrix, universal 60 FPS, and full ResonaDeck Plex telemetry visualization (requires later ResonaDeck release).
