# Game Theme Music 3.8.0 — Retro Ambient & Signature polish

**Public stable release.** Built on the developer-tested GTM 3.7.10 preview. No WebGL, fullscreen Showcase, or new audio stream.

## What changed
- Starlight Trails is now **Starlight Nucleus**: 205 parallax stars, three rotating colored particle shells, brilliant pulsing core, translucent orbital rings, responsive shooting stars. User-selected solid palettes remain respected; Auto/Prism/Rainbow use rich spectral colors.
- New **Retro Kaleidoscope** scene with three symmetric rotating prism/flower contours.
- New **Resonance Crown** GTM Signature scene with breathing arcs and an illuminated core.
- **GTM Signature** modes Pulse Engine and Arc Reactor receive expanded layered geometry, upgraded glow and bass-driven animation.
- **Retro Ambient • 2000s** scenes receive more fluid contour layers, coherent glow, improved star/spark detail, music-dependent motion and controlled palettes.
- All twelve styles continue using GTM’s passive telemetry, and the visualizer remains optional, Home-only, non-interactive, and clipped to its footer. No changes to music playback transport.

## Suggested checks
1. Install via Decky and confirm **3.8.0**; existing music and settings remain intact.
2. Select Starlight Nucleus, test Prism and CSS Auto color palettes; try quiet and bass-heavy tracks.
3. Select Retro Kaleidoscope, Pulse Engine, Arc Reactor, Resonance Crown, and check their distinctive shapes.
4. Open Steam context menus, Quick Access; verify visualizer yields and controller navigation behaves normally.
5. Restart Deck; confirm scene and mode settings persist.
6. Compare with 3.7.10 preview for performance and general audio behavior.

## Evidence and limitations
JavaScript/Python syntax and automated Canvas browser renders validate code paths, but only physical Steam Deck testing can establish stable SteamOS/Decky/CSS compatibility and accurate music-reactive behavior.
