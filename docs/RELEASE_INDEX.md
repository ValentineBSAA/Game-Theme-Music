To install, select the **Game-Theme-Music-4.6.7.zip** file under the release's **Assets**. GitHub's autogenerated source-code ZIP is **not** a complete Decky installer. The named ZIP includes YT-DLP/QuickJS binaries.

## Rollback

Keep a copy of your known-working ZIP and settings. Normal upgrades are designed to preserve settings and playlists, but downgrading across settings formats is not always guaranteed. The published 4.6.7 installer is standalone.
