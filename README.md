# 🎵 Game Theme Music
### 4.1.2 • Steam Deck beta candidate

Music and soundtrack companion for Steam Deck Gaming Mode: per-game soundtracks, Home Ambient music, shared Store music, and a colorful, music-reactive footer.

**[Releases and installable ZIPs](https://github.com/ValentineBSAA/Game-Theme-Music/releases)** · [4.1.2 beta notes](docs/RELEASE_NOTES_4.1.2.md) · [Hardware and regression results](TESTING.md) · [Source integrity](SOURCE.md)

> **Release status:** 4.1.2 is the creator-tested next beta; its release ZIP will be uploaded to Releases by the maintainer. The last published beta is [4.0.4](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.0.4), and [3.7.0](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V3.7.0) is the older stable release. **Install the named plugin ZIP under Releases, not GitHub's autogenerated "Source code" ZIP.**

## What's new through 4.1.2

| Feature | What it does |
| --- | --- |
| **Ambient Sleep Mode** | Under **Full Manager → Ambient**. Optional delayed restart/wake playback; **12 seconds by default**, adjustable **5–60 seconds**, with a gentle fade-in. |
| **Real Steam Deck sleep/restart handling** | Suspend-aware backend signals and playback guards prevent Ambient from immediately blasting on wake. |
| **Live ResonaDeck visualization** | GTM visualizes ResonaDeck's live Plex music through a read-only audio-data bridge. ResonaDeck **1.4.1** is the paired release. |
| **Exclusive audio focus** | GTM Ambient yields while ResonaDeck plays; Ambient recovers when Plex stops. |
| **Instant visualizer OFF** | ResonaDeck's Quick Access toggle immediately clears GTM's external visualizer, without interrupting Plex. |
| **Smoother footer rendering** | Refresh-aligned frame pacing, adaptive drawing quality, eased audio reactions, and no-flash scene handoffs. |
| **22 built-in Visual Worlds** | Retro Ambient, Classic Rhythm, GTM Signature and Anime Worlds; imported visualizer packs and scene Shuffle All. |
| **Music playback improvements** | Optional eight-second prebuffered crossfade, unlimited playlists, unified native Steam/Decky Store music and game soundtrack controls. |

The optional **Sleep Mode** toggle and delay slider belong under **Full Manager → Ambient**, not the general Settings page. **ON** delays automatic Ambient playback after waking or restarting; **OFF** restores previous immediate behavior. ResonaDeck's Plex sleep recovery is controlled separately in ResonaDeck.

## Steam Deck verification
The maintainer physically confirmed **GTM 4.1.2 Ambient recovery after both sleep/wake and a Steam Deck restart**. The updated visualizer pacing was also reported smooth in use. The 4.1.2 sleep/restart protection is **not** a claim that Plex automatically plays on reboot; ResonaDeck has its own, separately tested behavior. See [test evidence and limitations](TESTING.md).

## Installation
From **Releases**, download the appropriately named **Game-Theme-Music-4.1.2.zip** once the maintainer publishes the beta. Install the full ZIP through Decky Loader's manual plugin installer. Preserve your settings and playlists. For Plex-reactive visualizers, install the compatible ResonaDeck version and enable its visualizer bridge.
