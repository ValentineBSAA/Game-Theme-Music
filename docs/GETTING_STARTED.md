# Getting started with Game Theme Music

**[4.0.4 Public Beta](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.0.4)** · **[3.7.0 Previous Stable](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V3.7.0)**

## Install or upgrade
1. Download the actual installer `Game-Theme-Music-4.0.4-PUBLIC-BETA-RC4-PACK-SHUFFLE-PINBALL.zip` from [4.0.4 Assets](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.0.4). Do **not** select GitHub's “Source code” archive.
2. Enable manual/developer plugin installation in Decky Loader if necessary, install the ZIP and reload as prompted.
3. Keep your previous plugin runtime settings and downloaded music. Do not manually erase them during upgrades.

## Your playlists
**Games:** Steam and non-Steam games can have their own soundtracks. **Ambient:** Home music. **Store:** Native Steam Store + Decky Plugin Store now **share one** music session. The former 15-track limit is gone.

## Visual Worlds and transitions
Turn **Automatic 8-second crossfade** ON for buffered overlapping song handoffs, or OFF for normal transitions. Slow remote sources can still need loading time.

Choose the category and scene under Live Footer (Retro Ambient • 2000s, Classic Rhythm, GTM Signature, Anime Worlds). Choose **Music Reactive • Dynamic Spectrum** to color scenes from audio. Adjust brightness, sensitivity, height, bass boost and CSS theme blending. **Shuffle All Visualizers** changes scenes on actual song transitions but does not alter your song queue.

## Add and remove custom packs
Visualizer Packs → **Import ZIP** → Refresh → find scenes in their assigned category and the **Custom Packs** list. To remove use **Manage custom packs → Choose pack to remove → Review removal → Confirm**. The protected built-in scenes cannot be removed. Only validated declarative effects are supported, not arbitrary scripts.

## Other controls
The mini-player HUD remains optional. ResonaDeck audio focus remains cooperative. Full ResonaDeck Plex-to-GTM visualization is **not yet active** and needs a separate ResonaDeck update.
