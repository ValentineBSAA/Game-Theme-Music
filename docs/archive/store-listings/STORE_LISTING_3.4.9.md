# Game Theme Music 3.4.9 Store Listing

## Tagline
Your Steam Deck, with a soundtrack.

## Short description
Game Theme Music is a controller-first Steam Deck soundtrack manager with per-game playlists, Ambient and Store music, online preview/download, local imports, offline playback and artwork, library tools, and live theme integration.

## Full description
Turn Steam Deck Gaming Mode into a soundtrack system. Give Steam and non-Steam games ordered playlists, create separate Ambient music for normal Steam browsing, and give the Steam Store its own playlist. Search online and preview a track before downloading it, or import audio you already own. Downloaded tracks play local-first and cached or embedded artwork stays available offline.

The full-screen Soundtrack Manager is built for the Deck: physical LB/RB changes sections, A previews game tracks immediately, Preview is kept separate from the Active soundtrack selection, and the manager includes Games, Ambient, Store, Music Library, Find Music, and Import workflows. GTM also adapts to the live Steam/CSS Loader theme, supports per-track timing and fade controls, and includes diagnostics and storage/provider health tools.

### Highlights
