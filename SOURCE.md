# Source integrity and release packaging

## Current public release: Game Theme Music 4.5.8

**Published stable:** [V4.5.8](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.5.8) (November 5, 2026).

**Named installable asset:** `Game-Theme-Music-4.5.8.zip` (42,585,781 bytes). 
**SHA-256:** `4c3ace93a998a2dab7c023e507c19ab0dae8b5b5756bc1ea328e3a325b340324`.

The current main-branch runtime is synchronized to the **published 4.5.8 release ZIP** by the release-preparation workflow. The repository tracks source text, compiled runtime JavaScript, metadata and visualizer manifests; large standalone external executables such as bundled yt-dlp and QuickJS are **distributed in the installable ZIP** and are not committed to Git. The ZIP, not GitHub's autogenerated source archive, is the supported Decky install package.

The verified archive includes both yt-dlp and QuickJS. Its checksum is recorded in [docs/RELEASE_ASSET_SHA256_4.5.8.txt](docs/RELEASE_ASSET_SHA256_4.5.8.txt).

### Historical provenance

The previous stable [V4.4.9 release](https://github.com/ValentineBSAA/Game-Theme-Music/releases/tag/V4.4.9) remains available. The earlier reconstruction material for 4.4.9 is **historical only**; it is not needed to install or update to 4.5.8. Do not restore retired prerelease tags or recreate older assets as current packages.

### Verification scope

The maintainer tested GTM/ResonaDeck visualizer interoperability on Steam Deck, and the release archives have consistent version metadata and syntax checks. Those checks do not guarantee every possible SteamOS build, CSS theme, audio stream or controller combination. Consult [release notes](docs/RELEASE_NOTES_4.5.8.md), [release index](docs/RELEASE_INDEX.md), and [testing history](TESTING.md).
